Panduan ini terdiri dari 3 bagian: Persiapan Awal, Operasional Admin, dan Panduan Siswa.

BAGIAN 1 — OPERASIONAL ADMIN (Harian)

Bagian ini menjelaskan cara menggunakan Dashboard Admin untuk mengelola ujian.

1. Akses Dashboard Admin

  • Buka browser di server: http://localhost/tka-admin/login_admin.php
  • Username: admin
  • Password: (password yang sudah Anda ganti di config_admin.php)

2. Edit Siswa

Klik menu 👥 Edit Siswa.

  • Ubah Nama/Kelas: Ketik langsung di dalam kotak tabel, lalu klik 💾 Simpan.
  • Nonaktifkan Siswa: Klik 🚫 Nonaktifkan. Siswa ini tidak akan bisa login (berguna jika siswa sakit/izin).
  • Hapus Siswa: Klik 🗑 Hapus. Data siswa dan jawabannya akan hilang permanen.

3. Kelola Token (Reset)

Klik menu 🔑 Kelola Token.

  • Set Token Manual: Ketik 6 karakter (misal ABC123) di kotak, lalu klik ✏️ Set.
  • Reset Acak Satu Siswa: Klik 🔄 Reset di baris siswa tersebut. Token baru akan muncul.
  • Reset Semua Siswa: Klik tombol 🔄 Reset Semua Token di atas tabel.
⚠️ PENTING: Setiap kali token direset (baik satu maupun semua), KARTU PESERTA HARUS DICETAK ULANG agar siswa tahu token barunya.

4. Upload Soal (Termasuk Soal Bergambar)

Klik menu 📤 Upload Soal. Fitur ini akan menghapus semua soal lama dan menggantinya dengan soal dari file CSV yang Anda upload.

Format File CSV:

no;mapel;topik;level;soal;opsi_a;opsi_b;opsi_c;opsi_d;kunci

Cara Membuat Soal Bergambar:

  1. Siapkan Gambar: Copy file gambar (misal segitiga.jpg) ke folder C:\xampp\htdocs\tka\gambar\ (buat foldernya jika belum ada).
  2. Tulis di CSV: Gunakan tag HTML <img> di dalam teks soal. Tambahkan <br> untuk enter.
  3. Contoh penulisan:
    1;Matematika;Bangun Datar;sedang;Perhatikan gambar! <br> <img src="gambar/segitiga.jpg" width="200"> <br> Luas segitiga adalah ....;10 cm2;20 cm2;30 cm2;40 cm2;B
  4. Simpan CSV, lalu upload lewat menu Upload Soal.

5. Edit Soal Manual

Klik menu 📝 Edit Soal Manual. Gunakan menu ini jika Anda hanya ingin mengubah 1 atau 2 soal tanpa upload ulang CSV.

  • Pilih mapel (Matematika / B.Indonesia).
  • Ubah teks soal, opsi A-D, atau Kunci Jawaban.
  • Klik 💾 Simpan. Sistem akan otomatis menghitung ulang nilai siswa yang sudah ujian.

6. Reset Pelaksanaan Ujian

Klik menu ⚠️ Reset Pelaksanaan. Fitur ini digunakan jika ujian simulasi sudah selesai dan Anda ingin mengulang dari awal untuk ujian sungguhan.

  • Ketik kata RESET (huruf besar) untuk konfirmasi.
  • Klik tombol merah.
  • Sistem akan menghapus semua jawaban & sesi siswa. Soal dan Peserta tidak terhapus.

7. Analisis Hasil Ujian

Klik menu 📈 Analisis Hasil. Tampilannya mirip dengan file Excel yang dihasilkan Python, namun langsung di browser.

  • KR-20: Nilai reliabilitas ujian. Angka > 0.70 berarti soal ujian berkualitas baik.
  • p-value (Kesukaran): Jika < 0.30 berarti soal terlalu sulit. Jika > 0.70 berarti terlalu mudah.
  • Daya Beda: Jika < 0.20 berarti soal tidak bisa membedakan siswa pandai dan lemah (perlu diperbaiki).
  • Distraktor: Melihat opsi mana yang paling banyak dipilih siswa. Jika ada opsi yang 0 dipilih, berarti opsi pengecoh tidak berfungsi.
