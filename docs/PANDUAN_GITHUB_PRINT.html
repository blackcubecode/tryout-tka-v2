Panduan Instalasi via GitHub

Tryout TKA v2 — Sistem Ujian Berbasis LAN

Persiapan Awal

Pastikan server memiliki: XAMPP (Apache & MySQL), Python 3 (opsional), dan Safe Exam Browser.

Langkah 1: Unduh dari GitHub

  1. Buka https://github.com/blackcubecode/tryout-tka-v2
  2. Klik tombol hijau Code → Download ZIP.
  3. Extract ke D:\Tryout TKA v2.

Langkah 2: Rename File Konfigurasi

  1. Buka folder web. Rename config.example.php menjadi config.php.
  2. Buka folder admin. Rename config_admin.example.php menjadi config_admin.php.

Langkah 3: Edit Konfigurasi

Buka web\config.php dan admin\config_admin.php di Notepad. Ganti nama sekolah, password database (jika ada), dan password admin.

Langkah 4: Setup Database

Jalankan di PowerShell:

cd "C:\xampp\mysql\bin"
Get-Content "D:\Tryout TKA v2\db\01_schema.sql" -Raw | .\mysql.exe -u root
Get-Content "D:\Tryout TKA v2\db\seed_soal.sql" -Raw | .\mysql.exe -u root

Langkah 5: Copy Web ke XAMPP

Copy-Item "D:\Tryout TKA v2\web\*" "C:\xampp\htdocs\tka" -Recurse -Force
Copy-Item "D:\Tryout TKA v2\admin\*" "C:\xampp\htdocs\tka-admin" -Recurse -Force

Langkah 6: Buat Data Siswa

  1. Edit D:\Tryout TKA v2\peserta_contoh\daftar_siswa_contoh.csv.
  2. Jalankan: cd "D:\Tryout TKA v2\tools"; python buat_peserta.py.
  3. Masukkan ke database: Get-Content "D:\Tryout TKA v2\db\seed_peserta.sql" -Raw | .\mysql.exe -u root.

Langkah 7: Uji Akses

Buka browser:
Siswa: http://localhost/tka/login.php
Admin: http://localhost/tka-admin/login_admin.php

Langkah 8: Akses Jaringan & Firewall

Jalankan di PowerShell (Administrator):

New-NetFirewallRule -DisplayName "TKA Apache 80" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
New-NetFirewallRule -DisplayName "TKA MySQL 3306" -Direction Inbound -Protocol TCP -LocalPort 3306 -Action Allow

Langkah 9: Konfigurasi SEB (Safe Exam Browser)

Buka SEB Config Tool. Isi Start URL dengan IP server Anda (misal http://192.168.1.10/tka/login.php), atur blokir Alt+Tab, simpan sebagai file .seb, lalu copy ke PC siswa.

Selesai! Sistem siap digunakan. Untuk operasional harian, buka file PANDUAN_LENGKAP_V2.html di folder docs.
