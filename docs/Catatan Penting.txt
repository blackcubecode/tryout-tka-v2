
### Langkah 2: Simpan File dengan Benar
1. Di Notepad, klik **File** -> **Save As...**
2. Pada **Save as type**, pilih **All Files (*.*)**.
3. Pada **File name**, ketik: `README.md`
4. Pada **Save in**, arahkan ke folder: `D:\Tryout TKA v2-distribusi`
5. Klik **Save** (jika ditanya mau replace/timpa, klik **Yes**).

### Langkah 3: Update Git dan Push ke GitHub
Sekarang jalankan perintah ini di PowerShell **satu per satu** untuk mengunggah versi terbarunya:

```powershell
cd "D:\Tryout TKA v2-distribusi"

# Tambahkan perubahan file
git add README.md

# Buat commit baru
git commit -m "Update README: Fitur baru, arsitektur, dan panduan distribusi"

# Push ke GitHub
git push origin main
