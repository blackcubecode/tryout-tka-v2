Panduan Instalasi — Tryout TKA v2

Dari nol sampai ujian siap untuk admin sekolah.

Waktu: 2–3 jam untuk pertama kali.

Prasyarat: Siapkan semua installer saat masih ada internet, karena hari ujian tidak ada internet.

Jalur Contoh

  • Server: Windows 10/11 (64-bit), IP 192.168.1.10
  • Folder proyek: D:\Tryout TKA v2
  • Folder web: C:\xampp\htdocs\tka (UI siswa), C:\xampp\htdocs\tka-admin (dashboard admin)
  • Database: tka (MariaDB XAMPP)
  • URL ujian: http://192.168.1.10/tka/login.php
  • URL admin: http://192.168.1.10/tka-admin/login_admin.php

Ganti IP dan path sesuai sekolah Anda.

Tahap 1 — Pasang XAMPP

  1. Jalankan installer XAMPP.
  2. JANGAN install di C:\Program Files. Gunakan C:\xampp.
  3. Centang komponen: Apache, MySQL, PHP, phpMyAdmin.
  4. Klik Next → Install.
  5. Buka XAMPP Control Panel → Klik Start pada Apache dan MySQL.

Uji: buka browser http://localhost. Jika muncul halaman XAMPP, berarti berhasil.

Tahap 2 — Pasang Python (Opsional)

Diperlukan hanya jika ingin menggunakan script analitik atau generator peserta.

  1. Jalankan installer Python.
  2. PENTING: Centang "Add Python to PATH" di bagian bawah.
  3. Klik Install Now.
  4. Buka PowerShell baru, ketik python --version untuk verifikasi.

Tahap 3 — Copy File Proyek

Copy folder dari flashdisk ke server:

# Copy folder web ke htdocs\tka
Copy-Item "D:\Tryout TKA v2\web\*" "C:\xampp\htdocs\tka" -Recurse -Force

# Copy folder admin ke htdocs\tka-admin
Copy-Item "D:\Tryout TKA v2\admin\*" "C:\xampp\htdocs\tka-admin" -Recurse -Force

# Buat folder untuk file .seb dan gambar soal
New-Item -ItemType Directory -Force -Path "C:\xampp\htdocs\tka\download" | Out-Null
New-Item -ItemType Directory -Force -Path "C:\xampp\htdocs\tka\gambar" | Out-Null

Tahap 4 — Setup Database

4a. Buat database dan tabel

cd "C:\xampp\mysql\bin"
Get-Content "D:\Tryout TKA v2\db\01_schema.sql" -Raw | .\mysql.exe -u root

Verifikasi: .\mysql.exe -u root -e "SHOW DATABASES LIKE 'tka';". Harus muncul database tka.

4b. Isi 60 soal

Pastikan file CSV soal ada di D:\Tryout TKA v2\soal\.

cd "D:\Tryout TKA v2\tools"
python csv_ke_sql.py

cd "C:\xampp\mysql\bin"
Get-Content "D:\Tryout TKA v2\db\seed_soal.sql" -Raw | .\mysql.exe -u root

4c. Siapkan daftar siswa

Buka D:\Tryout TKA v2\peserta_contoh\daftar_siswa_contoh.csv di Notepad. Edit sesuai siswa sekolah Anda. Format:

nama;kelas
Ahmad Fauzi;6A
Budi Santoso;6A
Citra Dewi;6B

Aturan: Baris pertama jangan dihapus. Pemisah titik koma (;), bukan koma.

4d. Generate peserta + token + kartu

cd "D:\Tryout TKA v2\tools"
python buat_peserta.py

cd "C:\xampp\mysql\bin"
Get-Content "D:\Tryout TKA v2\db\seed_peserta.sql" -Raw | .\mysql.exe -u root

Cetak kartu: Buka D:\Tryout TKA v2\peserta_contoh\kartu_peserta.html di browser, tekan Ctrl+P.

PENTING: File kartu_peserta.html berisi token siswa. Jangan dibagikan ke grup WhatsApp atau Google Drive publik.

Tahap 5 — Konfigurasi Dasar

5a. Ganti nama sekolah

Buka C:\xampp\htdocs\tka\config.php, cari baris:

define('APP_SEKOLAH', 'SD Negeri Adireja Kulon');

Ganti dengan nama sekolah Anda. Lakukan hal yang sama di C:\xampp\htdocs\tka-admin\config_admin.php.

5b. Ganti password admin

Buka C:\xampp\htdocs\tka-admin\config_admin.php, cari baris:

define('ADMIN_USER', 'admin');
define('ADMIN_PASS', 'admin123');

Ganti password dengan yang kuat (misal: PasswordBaru2026!). Simpan.

Tahap 6 — Uji Akses

  1. Buka http://localhost/tka/login.php. Harus muncul halaman login siswa.
  2. Buka http://localhost/tka-admin/login_admin.php. Login dengan username/password baru.
  3. Dari PC siswa (jaringan yang sama), buka http://192.168.1.10/tka/login.php. Jika tidak bisa, cek firewall Windows.

Buka Firewall (sekali saja): Jalankan PowerShell sebagai Administrator, ketik:

New-NetFirewallRule -DisplayName "TKA Apache 80" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
New-NetFirewallRule -DisplayName "TKA MySQL 3306" -Direction Inbound -Protocol TCP -LocalPort 3306 -Action Allow

Tahap 7 — Buat File .seb (SEB Config Tool)

Buka SEB Config Tool, lalu ikuti panduan langkah demi langkah:

  1. General: Isi Start URL http://192.168.1.10/tka/login.php. Centang Allow quitting SEB, isi password. Hilangkan centang taskbar.
  2. Browser: Hilangkan centang address bar. Centang Allow JavaScript.
  3. Browser → URL Filter: Centang Enable URL filtering. Mode: Whitelist. Tambahkan: http://192.168.1.10/*.
  4. Security: Centang Kiosk mode, Block Alt+F4, Block Alt+Tab, Block Ctrl+Alt+Del.
  5. File → Save As... Simpan di D:\Tryout TKA v2\seb\tka-ujian.seb.
  6. Saat diminta enkripsi, pilih YES, masukkan password.

Tahap 8 — Uji End-to-End (Wajib!)

  1. Double-click file tka-ujian.seb. SEB harus terbuka penuh ke halaman login.
  2. Coba tekan Alt+Tab, Windows key, Ctrl+Alt+Del. Semua harus diblokir.
  3. Login dengan 1 siswa. Kerjakan 2-3 soal, klik Selesai. Pastikan nilai muncul.
  4. Cek di Dashboard Admin → Lihat Nilai. Nilai siswa tersebut harus muncul.
  5. Uji fitur admin: Edit Siswa, Upload Soal, Reset Pelaksanaan, dan Analisis Hasil.
Selesai! Sistem siap digunakan. Untuk operasional harian (cara reset, upload soal bergambar, dll), baca PANDUAN_LENGKAP_V2.html.
