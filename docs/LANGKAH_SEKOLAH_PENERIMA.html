Panduan Instalasi untuk Sekolah Penerima

Tryout TKA v2 — Sistem Ujian Berbasis LAN (Offline)

Terima kasih telah menggunakan sistem ini. Karena paket distribusi ini telah dibersihkan untuk alasan keamanan (menghapus data siswa dan password), Anda wajib melakukan beberapa langkah konfigurasi awal.

Langkah 1: Rename File Konfigurasi

  1. Buka folder web. Rename config.example.php menjadi config.php.
  2. Buka folder admin. Rename config_admin.example.php menjadi config_admin.php.

Langkah 2: Edit Konfigurasi Sekolah

Buka file config.php di Notepad, sesuaikan nama sekolah. Lakukan hal yang sama di config_admin.php.

Langkah 3: Import Database (SQL)

Buka PowerShell, lalu jalankan:

cd "C:\xampp\mysql\bin"
Get-Content "D:\Tryout TKA v2\db\01_schema.sql" -Raw | .\mysql.exe -u root

Langkah 4: Isi Soal & Buat Peserta Baru

Buka folder tools, jalankan python buat_peserta.py setelah Anda mengedit peserta_contoh\daftar_siswa_contoh.csv. Lalu masukkan ke database.

Langkah 5: Pindahkan Web ke XAMPP

Copy folder web ke C:\xampp\htdocs\tka, dan folder admin ke C:\xampp\htdocs\tka-admin.

🚨 PENTING (Konflik dengan Dapodik):
Jika di komputer server Anda terinstall Dapodik, XAMPP tidak akan bisa menyala di port 80/443. Anda wajib mengubah port XAMPP ke 8080. Panduan lengkapnya ada di dokumen PANDUAN_INSTALASI.html (Tahap 3). Jika tidak ada Dapodik, Anda bisa menggunakan port 80 biasa.
✅ Selesai!
Akses ujian siswa: http://localhost/tka/login.php (atau http://localhost:8080/tka/login.php jika pakai port 8080).
Akses Admin: http://localhost/tka-admin/login_admin.php (Username: admin, Password: admin123).
