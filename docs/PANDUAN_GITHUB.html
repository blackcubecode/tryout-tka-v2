Panduan Instalasi dari GitHub — Tryout TKA v2

Untuk Sekolah Penerima

Panduan ini menjelaskan cara mengunduh dan memasang sistem Tryout TKA v2 dari repositori GitHub. Pastikan komputer server Anda sudah terinstall XAMPP dan Python (opsional).

Tahap 1 — Unduh dari GitHub

  1. Buka browser dan kunjungi halaman repository GitHub Anda (contoh: https://github.com/blackcubecode/tryout-tka-v2).
  2. Klik tombol hijau "Code" → pilih "Download ZIP".
  3. Extract file ZIP yang terunduh (misalnya ke folder D:\Tryout TKA v2).

Alternatif via Git (jika terinstall):

cd D:\
git clone https://github.com/blackcubecode/tryout-tka-v2.git

Tahap 2 — Rename File Konfigurasi

Karena paket distribusi dibersihkan, file konfigurasi asli dihapus. Anda wajib me-rename file contoh:

  1. Buka folder web. Rename config.example.php menjadi config.php.
  2. Buka folder admin. Rename config_admin.example.php menjadi config_admin.php.

Tahap 3 — Edit Konfigurasi Sekolah & Database

  1. Buka file web\config.php di Notepad. Sesuaikan baris: 
    define('DB_PASS', ''); // Isi password MariaDB jika ada
define('APP_SEKOLAH', 'SD Negeri Nama Sekolah Anda');
  2. Buka file admin\config_admin.php di Notepad. Sesuaikan APP_SEKOLAH dan ganti password admin default: 
    define('ADMIN_PASS', 'PasswordBaru2026!');

Tahap 4 — Setup Database (SQL)

Buka PowerShell, lalu jalankan perintah:

cd "C:\xampp\mysql\bin"
Get-Content "D:\Tryout TKA v2\db\01_schema.sql" -Raw | .\mysql.exe -u root

Lalu, isi soal bawaan (jika ingin menggunakan 60 soal latihan):

Get-Content "D:\Tryout TKA v2\db\seed_soal.sql" -Raw | .\mysql.exe -u root

Tahap 5 — Copy Web ke XAMPP

# Copy folder web ke htdocs\tka
Copy-Item "D:\Tryout TKA v2\web\*" "C:\xampp\htdocs\tka" -Recurse -Force

# Copy folder admin ke htdocs\tka-admin
Copy-Item "D:\Tryout TKA v2\admin\*" "C:\xampp\htdocs\tka-admin" -Recurse -Force

Tahap 6 — Buat Peserta & Token Baru

  1. Buka D:\Tryout TKA v2\peserta_contoh\daftar_siswa_contoh.csv di Notepad. Ganti isinya dengan nama siswa sekolah Anda (format: nama;kelas).
  2. Jalankan perintah ini di PowerShell untuk generate token & kartu: 
    cd "D:\Tryout TKA v2\tools"
python buat_peserta.py
  3. Masukkan data peserta yang baru dibuat ke database: 
    cd "C:\xampp\mysql\bin"
Get-Content "D:\Tryout TKA v2\db\seed_peserta.sql" -Raw | .\mysql.exe -u root
  4. Cetak kartu peserta: buka D:\Tryout TKA v2\peserta_contoh\kartu_peserta.html di browser, tekan Ctrl+P.
✅ Selesai!
Akses UI Siswa: http://localhost/tka/login.php
Akses Dashboard Admin: http://localhost/tka-admin/login_admin.php (Username: admin, Password: sesuai yang Anda set di Tahap 3).
🚨 PENTING: Karena Anda mengunduh dari GitHub, pastikan Anda membaca PANDUAN_INSTALASI.html dan PANDUAN_LENGKAP_V2.html di folder docs untuk konfigurasi lanjutan (Firewall, IP LAN, dan pembuatan file SEB).
